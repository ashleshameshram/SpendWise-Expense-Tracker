# SpendWise — Expense & Savings Tracker

SpendWise is a modern personal finance dashboard built with React for managing transactions, savings goals, and financial progress.

## ✨ Features

### 💰 Expense & Income Management — 
* Add, edit, delete, search, filter, and sort transactions.

### 📊 Expense Analysis — 
* View spending by category with interactive charts and monthly summaries.

### 🎯 Savings Goals — 
* Create goals, add contributions, and track progress toward targets.

### 📈 Savings Insights — 
* Analyze monthly savings, growth, average savings, and completed goals.

### 🏆 Goal Completion History — 
* Automatically track when a savings goal reaches its target.

### 💾 LocalStorage — 
* Persist transactions, savings, and goals directly in the browser.

### 🎨 User Interface — 

* Clean and modern dashboard
* Responsive Bootstrap-based layout
* Consistent financial dashboard design
* Goal-specific icons and colors
* Progress indicators and status messages

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ashleshameshram/SpendWise-Expense-Tracker.git
```

### 2. Navigate to the project

```bash
cd SpendWise-Expense-Tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

## 📌 Project Highlights

SpendWise combines expense tracking and savings management into one dashboard. Savings progress is automatically calculated, completed goals are moved out of active goals, and their completion date is recorded in Savings Insights.
